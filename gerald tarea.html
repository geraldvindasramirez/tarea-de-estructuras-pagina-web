1. Introducción

Los lenguajes de marcado son pilares fundamentales en la informática. HTML se enfoca en la presentación visual y estructuración de páginas web en el navegador, mientras que XML se especializa en almacenar, describir y transportar datos estructurados entre diferentes aplicaciones.

2. Definición de un Documento Bien Formado

Un documento (HTML o XML) se considera bien formado si cumple con estas reglas:

  • Debe poseer un único elemento raíz que contenga a todos los demás.
  • Todas las etiquetas abiertas deben cerrarse correctamente.
  • Las etiquetas deben anidarse de forma apropiada.
  • Sensibilidad a mayúsculas y minúsculas.

3. Infraestructura del Documento

La infraestructura define el esqueleto básico que el intérprete procesa:

  • HTML: Utiliza el declarador de versión <!DOCTYPE html>, seguido del nodo raíz <html> que divide el contenido en <head> y <body>.
  • XML: Opcionalmente inicia con una instrucción de procesamiento como <?xml version="1.0" encoding="UTF-8"?> y un nodo raíz personalizado.

4. Etiquetas más Populares de HTML

Las etiquetas más empleadas para construir la estructura web básica son:

  • <h1> a <h6>: Encabezados y jerarquía de títulos.
  • <p>: Párrafos de texto.
  • <a>: Enlaces e hipervínculos.
  • <img>: Inserción de imágenes.
  • <ul> / <li>: Listas desordenadas y elementos.

5. Diferencias y Similitudes entre HTML y XML

Característica HTML XML
Propósito Visualizar información en la web. Transportar y almacenar datos.
Etiquetas Predefinidas y estandarizadas. Personalizables creadas por el usuario.
Similitudes Ambos usan marcas angulares < >, soportan anidación jerárquica y comparten un origen común en SGML.

6. Ejemplos Gráficos de Autoría Propia

Ejemplo básico de un archivo HTML:

<!DOCTYPE html>
<html lang="es">
<head>
    <title>Mi Web</title>
</head>
<body>
    <h1>Hola Mundo</h1>
</body>
</html>

Ejemplo básico de un archivo XML:

<?xml version="1.0" encoding="UTF-8"?>
<estudiante>
    <nombre>Gerald Vindas</nombre>
    <carrera>Ingeniería en Computación</carrera>
</estudiante>
